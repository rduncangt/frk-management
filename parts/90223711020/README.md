The fitted quantities describe the saw. Each FRK carries **one shared spare**, intended for an isolated lost or damaged screw.

## MS 462 — starter / fan housing

This is the main intended field use of the FRK spare: one of the screws securing the starter / fan housing to the crankcase. The screw is item **17**, separate from the complete starter assembly.

## MS 261 — cylinder mounting

Four of these screws secure the cylinder to the crankcase, item **20**. This application is included for identification and compatibility. Cylinder work would normally go to the shop in our operation.

![MS 261 cylinder and crankcase drawing, with screw item 20 highlighted in blue.](images/ms261-cylinder.png)

Source: STIHL MS 261 C-M spare-parts list, edition 10/02/2023; drawing on PDF page 8, parts table on page 9.
